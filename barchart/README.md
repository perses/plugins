# BarChart Panel Plugin

### How to install

This plugin requires react and react-dom 18 or 19.

Install peer dependencies:

```bash
pnpm add react@18 react-dom@18 # or react@19 react-dom@19
# with npm: npm install react@18 react-dom@18
```

Install the plugin:

```bash
pnpm add @perses-dev/bar-chart-plugin
# with npm: npm install @perses-dev/bar-chart-plugin
```

## Development

### Setup

Install dependencies:

```bash
pnpm install
```

### Get Started

Start the dev server:

```bash
pnpm run dev
```

Build the plugin for distribution:

```bash
pnpm run build
```
